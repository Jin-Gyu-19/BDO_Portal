데이터 업로드

날짜 · 전표번호 · 계정과목 · 계정코드 · 적요 · 차변 · 대변 · 거래처 · 거래처번호 컬럼을 포함한 전표(Journal Entry) 엑셀 파일을 업로드하세요.

감사 기준값 설정

여기서 설정한 PM(중요성 금액)은 JET-5 및 아래 "전체 절차 일괄 실행"에서 공통으로 사용됩니다. 언제든 값을 바꿀 수 있습니다.

미설정

전표 파일

클릭하여 엑셀 파일 선택 (.xlsx, .xls, .csv) 또는 이 영역으로 파일을 끌어다 놓으세요

컬럼 매핑 확인

자동으로 인식한 컬럼입니다. 다르게 인식된 항목이 있으면 직접 선택해 주세요.

전체 절차 일괄 실행

기본값(또는 위에서 설정한 PM) 기준으로 JET-3, 5, 6A/B/C, 7, 8A를 한 번에 실행하고 종합 대시보드로 이동합니다. JET-2(재무제표 대사)·JET-4(상대계정 분석)·JET-8B(연도별 거래처 비교)는 별도 파일 업로드나 계정 선택이 필요해 자동 실행에서 제외되며, 실행 후 안내해 드립니다.

⚠ 차대 불일치 전표

전표번호 기준 차변 합계와 대변 합계가 일치하지 않는 전표입니다. 이후 분석의 신뢰도에 영향을 줄 수 있습니다.

데이터 미리보기 (상위 25건)

JET-2

재무제표 대사

업로드된 전표 데이터로 계정과목별 시산표를 산출하고, 회사가 제시한 재무제표(또는 시산표) 금액과 일치하는지 확인합니다.

이용 방법

  1. JET-1에서 전표 데이터를 먼저 업로드합니다. 이 화면은 그 데이터로 계정과목별 시산표(차변합계·대변합계·잔액)를 자동으로 계산합니다.
  2. 표준 양식대로 회사 재무제표(또는 시산표) 파일을 준비합니다. 아래 "회사 재무제표(시산표) 파일" 카드의 [표준 양식 다운로드] 버튼을 누르면 정확한 형식의 엑셀 파일을 받을 수 있습니다. 계정과목, 계정코드, 금액 3개 컬럼이며, 계정과목·계정코드 중 하나만 정확해도 대사할 수 있습니다.
    예시
    계정과목  |  계정코드  |  금액
    현금      |  10100  |  15,000,000
    매입채무  |  21100  |  -8,200,000
    제품매출  |  40100  |  -320,000,000
    ※ 금액의 부호(차변/대변 방향)는 전표 데이터의 "차변−대변" 계산 방식과 동일한 부호 체계로 입력해야 정확히 대사됩니다. 자산·비용 계정은 양수(+), 부채·자본·수익 계정은 음수(−)로 입력하세요.
  3. "회사 재무제표(시산표) 파일" 영역에서 파일을 업로드한 뒤, 계정과목/계정코드/금액 컬럼 매핑을 확인하고 [재무제표 데이터 불러오기]를 클릭합니다.
  4. 매칭 기준을 선택합니다. 계정과목명이 전표와 재무제표에서 동일하게 표기되어 있으면 "계정과목명"을, 계정코드가 더 정확히 일치한다면 "계정코드"를 선택하세요.
  5. 계정과목명 표기가 미세하게 다르거나 반올림 등으로 작은 차이가 있을 수 있는 경우 허용 오차(원)를 입력하세요. 0으로 두면 완전히 일치하는 금액만 "일치"로 판정됩니다.
  6. [대사 실행]을 누르면 계정과목별로 일치 불일치 FS 없음 상태가 표시됩니다. 화면 하단에는 재무제표에는 있지만 전표 데이터에서 발견되지 않은 계정도 별도로 표시됩니다.
  7. 결과표 우측 상단의 [엑셀 다운로드] 버튼으로 대사 결과 전체를 엑셀 파일로 저장할 수 있습니다.
먼저 JET-1에서 전표 데이터를 업로드하세요.데이터가 준비되면 이 화면에서 대사를 진행할 수 있습니다.

회사 재무제표(시산표) 파일

아래 표준 양식대로 계정과목, 계정코드, 금액 3개 컬럼으로 준비해서 업로드하세요. (계정과목명 또는 계정코드 중 실제 대사에 쓸 컬럼 하나만 정확해도 되고, 나머지 하나는 비워둬도 됩니다.)

계정과목 | 계정코드 | 금액
현금 | 10100 | 15,000,000
매입채무 | 21100 | -8,200,000
제품매출 | 40100 | -320,000,000
매출원가 | 50100 | 210,000,000
※ 부호 기준: 자산·비용 계정은 양수(+), 부채·자본·수익 계정은 음수(−)로 입력해야 전표 데이터의 "차변−대변" 계산과 정확히 대사됩니다.
클릭하여 엑셀 파일 선택 계정과목, 계정코드, 금액 컬럼 포함 (표준 양식 권장)

대사 기준

계정과목별 대사 결과

재무제표에는 있으나 전표 데이터에 없는 계정

JET-3

주말 전표 검토

토요일 또는 일요일 날짜로 작성된 전표를 전표번호 단위로 검출합니다. 통상적이지 않은 시점의 회계처리 여부를 확인하는 절차입니다.

먼저 JET-1에서 전표 데이터를 업로드하세요.

주말 전표 목록

행을 클릭하면 전표의 세부 라인을 확인할 수 있습니다.

JET-4

상대계정 분석

특정 계정과목을 지정하면, 해당 계정이 포함된 전표에서 함께 회계처리된 상대계정을 집계합니다. 비정상적인 상대계정 조합을 식별하는 데 사용합니다.

먼저 JET-1에서 전표 데이터를 업로드하세요.

상대계정 집계

행을 클릭하면 해당 상대계정과 연결된 전표 세부 내역을 확인할 수 있습니다.

JET-5

중요성기준(PM) 초과전표

지정한 중요성 금액(PM) 이상의 거액전표를 검출합니다. 전표 합계 기준 또는 라인(차/대변 개별 금액) 기준으로 조회할 수 있습니다.

먼저 JET-1에서 전표 데이터를 업로드하세요.
미설정

PM 초과 전표 목록

JET-6

이상징후 종합분석

Round Number 회계처리, 결산일(분기 말)에 생성된 전표, 다른 전표 대비 비정상적으로 드물게 쓰인 상대계정 조합을 각각 조회합니다. 세 개의 독립된 검사로 구성되어 있으며 필요한 것만 실행하면 됩니다.

먼저 JET-1에서 전표 데이터를 업로드하세요.

6-A. Round Number 전표

차변 또는 대변 금액이 지정한 단위로 딱 떨어지는 라인을 검출합니다. 실제 거래보다 임의로 만들어졌을 가능성이 있는 금액을 식별하는 절차입니다.

6-B. 결산일 생성 전표

분기 결산일에 생성된 전표를 검출합니다. 특정 날짜(MM/DD) 또는 임의의 날짜 범위 중 하나를 선택해서 조회할 수 있습니다.

6-C. 비정상적인 상대계정 조합

계정과목별로 평소 함께 쓰이는 상대계정의 빈도를 분석해, 그 계정 기준으로 드물게 사용된 상대계정 조합을 찾습니다.

JET-7

중복 전표 탐지

날짜·계정과목·금액·거래처가 동일한 라인이 여러 번 나타나는 경우를 검출합니다. 이중 입력 실수나 반복적인 부정 거래를 식별하는 절차입니다.

먼저 JET-1에서 전표 데이터를 업로드하세요.

중복 의심 그룹

JET-8

거래처 분석

거래처별 거래 집중도와, 처음 등장한 거래처의 거래가 거액인 경우를 확인합니다.

먼저 JET-1에서 전표 데이터를 업로드하세요.

8-A. 거래처 집중도

거래처별 거래금액·건수를 집계해 상위 거래처와 전체 대비 비중을 확인합니다.

8-B. 연도별 거래처 순위 비교

전년도 파일을 업로드하면, JET-1에서 업로드한 데이터를 "올해"로 놓고 지정한 계정과목 기준으로 거래처별 거래액을 연도별로 비교합니다. 올해만 있는 거래처(신규), 전년도만 있는 거래처(거래 중단), 거래빈도가 높은 거래처를 한눈에 확인할 수 있습니다.

클릭하여 전년도 파일 선택 JET-1과 동일한 9개 컬럼 형식 (.xlsx, .xls, .csv)
JET-9

월별 거래액 분석

특정 계정과목을 선택해 월별 차변·대변·순액 추이를 확인합니다. 특정 월에 비정상적으로 몰린 거래나 계절적 패턴을 벗어난 이상 변동을 식별하는 데 활용합니다.

먼저 JET-1에서 전표 데이터를 업로드하세요.
